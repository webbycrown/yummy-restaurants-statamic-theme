# Yummy Food Restaurant - Statamic Starter Kit

At Yummy Food Restaurant, we bring a stylish and dynamic restaurant theme powered by Statamic CMS. Crafted with flexibility and performance in mind, this theme makes it effortless to present your culinary brand through an elegant design and smooth content management.

With dedicated pages for About, Menu, Blog, Portfolio, Contact, and Chef, Yummy Food Restaurant allows you to showcase your story, highlight signature dishes, share updates, display food photography, and connect with customers all in one modern, easy-to-manage platform.

## Installation

Follow the [Starter Kit installation instructions](https://statamic.dev/starter-kits/installing-a-starter-kit) to get started with Yummy Food Restaurant.
Make sure you're running **Statamic 5.x** for compatibility.

### Installing into an existing site

```bash
php please starter-kit:install webbycrown/yummy-restaurants-statamic-theme
```

### Installing via the Statamic CLI Tool

If you have the [Statamic CLI Tool](https://github.com/statamic/cli) installed, create a new Statamic installation with Yummy Food Restaurant in one command:

```bash
statamic new my-site webbycrown/yummy-restaurants-statamic-theme
```
